生成一个可以显示canvas动画特效的vue组件（用JavaScript写，文件格式为vue），用于RPG游戏的战斗特效。传入参数：（type）播放不同的动画，特效的播放时长（period，默认0.5秒），初始面朝角度（initAngle），旋转速度（spinSpeed），缩放（scaleX，scaleY），动画出现在屏幕中的起始位置坐标（fromX，fromY）和结束位置坐标（toX,toY），这10个参数。可选择的动画包括：雷击特效（蓝紫色）、弯弧特效（灰色+白色，刀光剑气+黑色多重影）、镭射特效（灰色+白色）、气团特效（灰色+白色，不规则气团形状+黑色多重影）、火焰特效（红+黄色，雾气和燃烧）、爆炸特效（红+黄色，扩散粒子效果）、治疗特效（绿色，粒子效果）、护盾特效（潜绿色+蓝色）、阵法特效（潜蓝色，有粒子效果）。每个特效都要炫酷迅捷和具有强烈打击感，每个特效都要在“刚开始时淡入”并且“快结尾时淡出”，每个特效的移动速度的变化率是“先慢、后快、最后再慢”。
